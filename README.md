# simple-resume-website

Welcome to the repository for my personal resume website! This site showcases my professional experience, technical skills, featured projects, and education.

## Features
- **Responsive Design:** Fully optimized for desktop viewing.
- **Project Showcase:** Highlights of my recent work.
- **Interactive Resume:** An easy-to-read layout of my work history and education.
- **Contact Integration:** A direct way for recruiters and clients to get in touch.

## Built With
- HTML
- CSS
- JavaScript
